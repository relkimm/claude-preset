# claude-preset

Install curated Claude Code command presets with one command.

## Install

```bash
npx claude-preset
```

## What it does

Installs 12 productivity presets to your `.claude/commands` directory:

| Command | Description |
|---------|-------------|
| `/commit` | Generate commit message |
| `/pr` | Generate PR description |
| `/review` | Code review |
| `/debug` | Debug issues |
| `/test` | Write tests |
| `/lint` | Fix linting issues |
| `/security` | Security audit |
| `/refactor` | Refactoring suggestions |
| `/optimize` | Performance optimization |
| `/cleanup` | Remove dead code |
| `/explain` | Explain codebase |
| `/ship` | Pre-deploy pipeline |

## Languages

- English (`en`)
- 한국어 (`ko`)

## Usage

After installation, use commands in Claude Code:

```
/commit
/review
/ship
```
