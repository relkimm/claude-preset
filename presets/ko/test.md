실용적이고 실행 가능한 테스트를 작성합니다.

## 사용법
- `/test` - 테스트 필요한 코드 찾아서 작성
- `/test [파일명]` - 해당 파일 테스트 작성
- `/test [함수명]` - 해당 함수 테스트 작성

## 분석
1. `$ARGUMENTS`가 있으면 해당 대상에 집중
2. 없으면 최근 변경된 파일 중 테스트 없는 것 찾기
3. 프로젝트의 테스트 프레임워크 감지 (Jest, Vitest, Pytest 등)
4. 설정이 없으면 설치 방법 안내

## 테스트 케이스
각 함수/컴포넌트마다:
- **정상 케이스**: 일반적인 입력으로 정상 동작
- **엣지 케이스**: 빈 값, 큰 값, 특수 문자 등
- **에러 케이스**: 잘못된 입력, 예외 상황

## 테스트 형식

```javascript
describe('함수이름', () => {
  it('기본 동작 테스트', () => {
    const result = 함수이름(input)
    expect(result).toBe(expected)
  })

  it('엣지 케이스 처리', () => {
    // 빈 값, null 등
  })

  it('에러 처리', () => {
    expect(() => 함수이름(invalid)).toThrow()
  })
})
```

## 출력
- 바로 실행 가능한 완전한 테스트 코드
- 필요시 설정 방법 포함
- 테스트 실행 명령어 제공

사용: `/test` 또는 `/test src/utils.js`
