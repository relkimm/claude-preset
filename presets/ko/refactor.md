코드를 더 깔끔하고 유지보수하기 좋게 개선합니다.

## 사용법
- `/refactor` - 전체 프로젝트 스캔
- `/refactor [파일명]` - 특정 파일만 분석
- `/refactor [설명]` - 특정 문제 해결

## 찾는 문제들

**코드 품질**
- 중복된 코드 (복사-붙여넣기)
- 너무 긴 함수 (30줄 이상)
- 복잡한 중첩 (if 안에 if 안에 if...)
- 불명확한 변수/함수 이름
- 매직 넘버 (`if (status === 3)`)

**불필요한 코드**
- 사용하지 않는 import
- 호출되지 않는 함수
- 주석 처리된 코드
- console.log, debugger 등

**구조 문제**
- 한 함수가 너무 많은 일을 함
- 잘못된 책임 분리
- 불필요한 복잡성

## 출력 형식

```
### [파일명:라인]
문제: [무엇이 문제인지]

현재:
[문제 코드]

개선:
[개선된 코드]

이유: [왜 더 나은지]
```

## 원칙
- 동작은 그대로, 구조만 개선
- 한 번에 하나씩 변경
- 과도한 추상화 지양
- 가독성 우선

사용: `/refactor` 또는 `/refactor src/utils.js`
