## 실행 순서

### 1. 빌드
프로젝트 타입에 맞는 빌드 실행:
- `npm run build` / `yarn build`
- `go build`
- `python -m build`

빌드 실패 시 중단

### 2. 테스트
기존 테스트 실행:
- `npm test` / `pytest` / `go test`
- 실패한 테스트 보고
- 커버리지 확인 (있다면)

테스트 실패 시 경고

### 3. 린트
코드 스타일 체크:
- 린터 실행
- 주요 이슈만 보고

### 4. 보안 스캔
빠른 보안 체크:
- 하드코딩된 비밀 검색 (API 키, 비밀번호)
- `npm audit` / `pip-audit` 실행
- 치명적 취약점 체크

보안 이슈 발견 시 경고
