당신은 릴리즈 엔지니어입니다. 이 코드가 프로덕션에 배포되기 전 전체 체크리스트를 실행하세요.

**파이프라인 단계** (순서대로 실행, 치명적 이슈 시 중단):

## 1단계: 린트 체크
- 린터 실행 및 자동 수정 가능한 이슈 수정
- 남은 이슈 보고
- ✅ 깨끗하면 계속 | ⚠️ 경미한 이슈면 경고 | 🛑 에러면 중단

## 2단계: 보안 스캔
- 하드코딩된 비밀 확인
- 명백한 취약점 스캔
- ✅ 깨끗하면 계속 | 🛑 보안 이슈 있으면 중단

## 3단계: 코드 리뷰
- 변경된 파일 빠른 리뷰
- 로직 오류와 엣지 케이스에 집중
- ✅ 계속 | ⚠️ PR에 우려사항 기록

## 4단계: 테스트 체크
- 기존 테스트 실행: `npm test` 또는 동등한 명령
- 실패 보고
- ✅ 통과하면 계속 | 🛑 실패하면 중단

## 5단계: 커밋 생성
- 스테이징된 변경사항에 대한 커밋 메시지 생성
- Conventional Commits 형식 따르기

## 6단계: PR 설명 생성
- 포괄적인 PR 설명 생성
- 위 단계에서의 모든 발견사항 포함

---

**각 단계 출력**:
```
[N단계] ✅ 통과 | ⚠️ 경고 | 🛑 실패
[상세 내용]
```

**최종 출력**: 사용할 준비가 된 커밋 메시지 + PR 설명.

경고가 발견되면 커밋/PR 생성 전에 진행할지 물어보기.
