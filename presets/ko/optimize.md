성능 문제를 찾아서 개선합니다.

## 사용법
- `/optimize` - 전체 스캔
- `/optimize [파일명]` - 특정 파일 분석
- `/optimize [설명]` - 특정 문제 해결

## 찾는 문제들

**알고리즘**
- 중첩 반복문 (O(n²))
- 반복문 내 I/O 작업
- 불필요한 재계산
- 비효율적 데이터 구조

**메모리**
- 메모리 누수
- 과도한 메모리 사용
- 불필요한 객체 생성

**네트워크**
- 과도한 API 호출
- 필요 이상의 데이터 fetch
- 캐싱 미적용

## 출력 형식

```
파일:라인

문제: [무엇이 느린지]

현재:
[문제 코드]

최적화:
[개선 코드]

효과: [예상 성능 향상]
```

## 우선순위
1. 사용자 체감 (페이지 로딩, UI 반응)
2. 실행 빈도 (매 요청, 매 클릭)
3. 비용 (DB 쿼리, API 호출)

## 원칙
- 측정 가능한 개선
- 가독성 유지
- 실질적 영향에 집중

사용: `/optimize` 또는 `/optimize src/api.js`
