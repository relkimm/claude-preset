**제공할 내용**:

1. **개요** (2-3문장)
   - 이 프로젝트는 무엇을 하나요?
   - 누가 어떻게 사용하나요?

2. **아키텍처**
   ```
   [주요 컴포넌트의 ASCII 다이어그램]
   ```
   - 사용된 주요 디자인 패턴
   - 주요 데이터 흐름

3. **구조**
   ```
   /src
     /api      - [목적]
     /models   - [목적]
     ...
   ```

4. **진입점**
   - 실행이 시작되는 곳
   - 주요 사용자 facing 흐름

5. **핵심 개념**
   - 도메인 용어와 그 의미
   - 중요한 추상화

6. **의존성**
   - 주요 외부 라이브러리
   - 각각을 사용하는 이유

**특정 파일/함수의 경우**:
- 무엇을 하는지
- 왜 존재하는지
- 나머지와 어떻게 연결되는지
- 직관적이지 않은 부분
