## 사용법
- `/explain` - 프로젝트 전체 개요
- `/explain [파일명]` - 특정 파일 설명
- `/explain [함수/개념]` - 특정 부분 설명

## 프로젝트 전체 설명

```
목적: [이 프로젝트가 하는 일]

구조:
/src
  /components - [역할]
  /utils - [역할]

실행: [설치 및 실행 방법]

핵심 파일:
- [파일1]: [역할]
- [파일2]: [역할]

데이터 흐름:
[사용자 입력 → 처리 → 출력]
```

## 파일/함수 설명

```
역할: [무엇을 하는지]

동작:
1. [단계 1]
2. [단계 2]
3. [단계 3]

입력: [파라미터와 용도]
출력: [반환값]

관계:
- 호출하는 곳: [어디서 사용]
- 호출하는 것: [무엇을 사용]

예시:
[간단한 사용 예]
```

- 쉬운 언어 사용

- 필요시 비유 활용
